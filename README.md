# Brilliant Board

What I would like you to do for me is to build a Kanban board. I want it to have the following features. I'd like it to have a complete, let's say, a to-do and in progress section. But first, I want you to ask me questions to verify your understanding, just to make sure that we crush the features down. I want the design to be interactive and attractive, very beautiful. And I'd also like an integrated AI chatbot that I can ask questions at any time. And I also want the ability to save all of this information in a database so that I can come back and use it whenever I want in the future. 

Also use the attached images as your design reference.
